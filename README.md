# Ashtanga Primary Series — Flashcards

A single-page, offline flashcard app for learning the Ashtanga Primary Series (Yoga Chikitsa):
Sanskrit + English names, pronunciation, drishti, breath counts, breath-led cues, pose images,
and a 3-lens categorization (family / spinal action / energy) plus "How to sequence" and
"Cue by family" guides.

## Run it
- **Locally:** open `index.html` in any browser. (Keep the `assets/` folder next to it.)
- **Hosted (GitHub Pages):** enable Pages on this repo (Settings - Pages - deploy from `main` / root).
  It will be served at `https://<your-username>.github.io/<repo-name>/`.

## Contents
- `index.html` — the whole app (HTML/CSS/JS, no build step, no dependencies)
- `assets/poses/` — pose images
- `assets/poses-manifest.json` — image source/license metadata
- `CREDITS.md` — image attributions

## Images
Pose images are Creative Commons / public domain (see `CREDITS.md`). ~48 of 64 poses have images;
the rest show an "image coming soon" placeholder.
